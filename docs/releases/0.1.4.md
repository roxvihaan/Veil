# Veil Terminal 0.1.4

- Adds a 6-point gap around `veil pip bound` (and plain `veil pip`).
- Keeps that gap when resizing the PiP or split; aspect ratio is preserved.
- Leaves `veil pip unbound`, terminal padding, and input handling unchanged.

Download the Apple Silicon DMG and drag Veil Terminal to Applications. Save your terminal work and quit Veil before replacing it. Homebrew users can run `brew update && brew upgrade --cask roxvihaan/tap/veil`.

Requires macOS 12 or newer. Ad-hoc signed, not Apple-notarized; use Apple's per-app approval flow only if you trust the source. Accessibility is required for PiP. A SHA-256 checksum is included.

Validation: full packaged-app tests, bound/unbound geometry and resize checks, signing verification, DMG integrity/layout tests, and Finder installer inspection.
