# Veil Terminal 0.1.3

## What's new

- `veil pip bound` fits an explicitly selected external PiP window to the invoking split. Plain `veil pip` uses bound mode.
- `veil pip unbound` follows the split's position while keeping PiP size independent. PiP discovery is app-independent, subject to macOS Accessibility support.
- Dropping an image or GIF at an empty prompt runs `veil image <path>`. ASCII panes can be moved while preserving their terminal session.
- Added native Messages/Contacts and Spotify commands, with usage documentation in the README.
- Kept the right-click menu focused on split actions. Docking preserves shells and scrollback.
- Stabilized Veil's local signing identity to prevent future rebuilds from invalidating Accessibility grants. Existing grants from older builds may need one manual removal/re-add in System Settings.

## Install

Download `Veil-0.1.3-arm64.dmg`, open it, and drag **Veil Terminal** onto **Applications**. Save your work and quit the old Veil before replacing it.

Homebrew: `brew update && brew upgrade --cask roxvihaan/tap/veil` (or `brew install --cask roxvihaan/tap/veil` for a first installation).

Apple Silicon only; macOS 12 or newer. This build is ad-hoc signed, **not Apple-notarized**. If macOS blocks it, use Apple's per-app approval process only if you trust this source; do not disable Gatekeeper or remove quarantine.

The accompanying `.sha256` file verifies the download. PiP requires Accessibility access and a source app that exposes window movement/resizing; native behavior can vary across apps and displays.

Validation: packaged-app command, PTY latency, split sizing, PiP mode/session, signing identity, and DMG integrity/layout tests.
